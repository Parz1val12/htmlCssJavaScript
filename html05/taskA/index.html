Inline and Internal CSS Practice

This page practices two ways to add CSS: inline styles and an internal stylesheet. The third way, an external stylesheet, is in the 05b task.

Element Selectors

An element selector uses the tag name, like h2. It styles every tag of that type. After TODO 2, all three h2 headings on this page turn green at once.

Class Selectors

A class selector starts with a dot, like .intro.

One class can be used on as many tags as you want. This paragraph uses the same class as the one above.

ID Selectors

An ID selector starts with a hash, like #special. An id can only be used on one tag per page.

When you're done: the h1 is orange, all three h2 headings are green, two paragraphs have a yellow background, and the ID sentence is red and bold.
