Learning web design becomes easier when you can see the page grow and understand how elements stack on top of each other. This is a practical example of how HTML and CSS work together to build structure and style.

More content means more height, and more height means the page can extend beyond the browser window. That is exactly what we want here so the page becomes taller than the visible area.

It is useful to practice with repeated blocks of text because it helps you understand spacing, flow, and rhythm. The browser keeps adding each element below the last one until the page reaches a natural new height.

As you build bigger pages, you will notice how borders, margins, paddings, and sticky headers all affect the final layout. A little extra content makes it much easier to see those behaviors.
